Web GIS Demo

Interactive GIS Map Viewer

A lightweight GitHub Pages web GIS interface with responsive layout, modern styling, and professional map controls.

Project Summary

This example demonstrates a polished GIS site with a responsive map panel, layer switcher, floating legend, and curated city marker dataset.

  • Interactive Leaflet basemap with topographic option
  • Major UK city markers with popups
  • Optimized for GitHub Pages and responsive displays

Quick Tips

  • Use the layer control to toggle basemaps.
  • Zoom into a city by clicking its marker.
  • Read the legend for map context and navigation.

Built for branch-based development and hosted demos. Use this branch to refine visual design and map usability on GitHub Pages.
